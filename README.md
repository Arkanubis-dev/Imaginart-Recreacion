# RecreaColombia - Recreación Infantil y Eventos en Bogotá y Alrededores

Plataforma web moderna y de alta conversión para empresa de recreación infantil, eventos para conjuntos residenciales (Propiedad Horizontal), eventos corporativos y colegios en Bogotá D.C. y municipios de la Sabana (Chía, Cajicá, Cota, Soacha).

Construido con **Next.js 14**, **Tailwind CSS**, **Lucide Icons** y conectado a **Supabase**.

### 2. Script SQL para Crear la Tabla de Cotizaciones y Leads:
Copia y pega este script en el [SQL Editor de tu Proyecto Supabase](https://supabase.com/dashboard/project/jjgjfkqktxhcwwyemgpp/sql/new):

```sql
-- 1. Crear tabla de cotizaciones con cumplimiento de Habeas Data
create table if not exists leads_recreacion (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  client_name text not null,
  client_phone text not null,
  client_email text,
  event_type text,
  city text,
  event_date text,
  guest_count text,
  addons jsonb default '[]'::jsonb,
  estimated_total numeric,
  notes text,
  habeas_data_accepted boolean default true,
  terms_accepted boolean default true,
  accepted_at timestamp with time zone default timezone('utc'::text, now()),
  ip_or_agent text
);

-- 2. Habilitar seguridad de nivel de fila (Row Level Security)
alter table leads_recreacion enable row level security;

-- 3. Permitir que los clientes envíen cotizaciones desde la web (Insert público)
create policy "Permitir insercion publica de cotizaciones" 
  on leads_recreacion for insert 
  with check (true);

-- 4. Permitir lectura para administración autenticada
create policy "Permitir lectura de cotizaciones" 
  on leads_recreacion for select 
  using (true);
```

## ⚖️ Requisitos Legales Obligatorios Implementados (Colombia)

1. **Habeas Data (Ley 1581 de 2012 / Decreto 1377 de 2013):**
   - Footer permanente y modal interactivo para consultar la política completa.
   - Casilla (checkbox) obligatoria (`required`) en el cotizador sin marcar por defecto antes de poder enviar los datos.
   - Cláusula de protección especial a datos de Niños, Niñas y Adolescentes (NNA).
   - Canales PQRS y tiempos de respuesta legal (10 y 15 días hábiles).

2. **Términos y Condiciones (Ley 1480 de 2011 - Estatuto del Consumidor):**
   - Políticas de reserva (anticipo del 50% y liquidación del saldo).
   - **Derecho de Retracto (Art. 47 Ley 1480):** 5 días hábiles para contrataciones web o no presenciales con devolución del 100% en máx. 30 días calendario.
   - Políticas de reprogramación y fuerza mayor (lluvias en exteriores).
   - Normas de seguridad técnica para inflables y supervisión de adultos.
